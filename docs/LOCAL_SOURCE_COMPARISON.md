# Local source calculation comparison · tax year 2025

The App can run the supported source-derived ordinary wage calculation beside
its current IRS calculation. Open **Documents → Try local calculation
comparison** for an independent example, or **Compare local source calculation**
after inspecting a binary source and select the matching local resource files.
All calculations and files stay on the device.

The original resources are not shipped. The approved local 2025 profile checks
nine exact file identities, complete resource directories, selected forms,
program records and tables. Independently authored demonstration resources are
shipped separately and labeled in the interface. They demonstrate the workflow;
they do not establish original-product compatibility.

The loader binds each stored scalar through the full field identity and saved
D2 mapping, then checks its current field definition, stored type and flags.
Binary v5 obtains table definitions from the same effective registry. Existing
forms are read from the source; absent calculation forms are listed explicitly
and require confirmation. No native forms are created. The bounded source
carrier limit is nine. XML import retains its separate existing contract.

Users confirm filing status, deduction, payments, interest/dividend summaries,
blank choices and the source/current-return comparison pair. The App recomputes
the **complete current return** with the unchanged IRS engine. It checks the
source bytes, source metadata profile and full current input identities. It does
not accept a supplied summary in place of the current return. Input changes
cancel confirmations and prior results. Pending replies and audit downloads
check their current inputs again. Closing the dialog terminates its worker.

The USD comparison shows total tax, payments and signed balance, defined as tax
minus payments. A positive balance is due; a negative balance is overpaid. Source
refund disposition has not been executed. Different reviewed input contexts can
explain a difference. The App's validation blockers remain visible.

Audit exports use the ordinary native Save window on desktop and Android.
Comparison results never replace the saved IRS calculation, mutate the source,
or enable filing. Proposed source writes remain audit records with commit
permission false. Original template initialization, field fixup, complete
interpreter/dependency scheduling, all upstream amount producers, native row
creation/UUID recovery and whole `.tax` compatibility remain unfinished.
Original licensed runtime executions and original taxpayer fixtures remain zero.
