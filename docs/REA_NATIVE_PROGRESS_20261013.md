# REA 原版二进制拆解：TurboTax 2025（2026-10-13）

已用三个子智能体并行分析原版二进制。主程序完成 61 个不同函数的 Ghidra dossier；原生桥另有 4 个。这里按原文件 SHA256 与函数地址去重，排除同函数的 raw 补证、失败调用、符号和页面清单。函数数量不等于付费功能数量。

## 已确认的机制

| 分析线 | 已读到的原版机制 | 尚未证明的范围 |
| --- | --- | --- |
| 税档案读写 | 文件头分类；Legacy/TaxML加载与保存；内部header版本检查；TaxReturns根、表实例与字段状态读写 | 完整 archive 成员、加密 envelope、全部旧版本兼容与实际.tax往返 |
| 计算引擎 | 字段依赖入队、失效重算、缓存与最终写回；算术委派追到 FullOperatorMath；BigFixedPoint舍入；protobuf图加载 | 全部旧规则、运算类型、每项税公式、原版结果对照 |
| 访谈与审查 | 原生数据提交/导航/回调；当前表实例与字段绑定；W-2和股票交易字节码分支 | 完整页面像素对齐、原版运行、远程服务等价 |

**真正来自原版的三组关键发现：**

1. 金额经定点十进制转换后计算。减少小数位时，正负半单位都向远离零取整。当前独立实现的整美元函数已对照这份静态合同检查了7个适用案例；另外10个整数模型案例通过。此检查没有执行原版，也不证明完整税务结果一致。
2. 页面上的计算缓存与最终写回是不同步骤。字段修改触发依赖入队，重新计算和解释；WriteValuesToOutput最后写入数据源。复刻需要保留档案、表实例、页面、未保存修改和回调状态。
3. 原包有30个XPRF规则容器，已索引58,526条资源记录。从原始主程序中的Nodes.proto描述符及资源5036解析了64,641个节点。原生Reader确认长度、Header、节点循环、可选排序数据。50,555个calculated nodes中45个标为explanation_only，包含若干1040汇总终点；其余未标该位并不等于已经逐项恢复公式或验证执行。后续已恢复一段 W-2 多份本地聚合路径，但该 legacy 汇总字段到 TKE 输入的最终绑定仍有断点。
