## What now has a concrete reconstruction contract

**Investment basis correction:** original JVM bodies show a scoped, absolute replacement and applied-state guard. The independent App now performs actual tax recomputation and local persistence. See [the usable workflow and checks](INVESTMENT_BASIS_CORRECTIONS.md).

**W-2 aggregation and mapping:** the original decompressor supports an independently written decoder of a packaged mapping resource. All 174 blocks pass their stored CRCs. The recovered mapping and exact legacy instruction segments connect the W-2 wage summary to the wage worksheet and Form 1040 wage field. Local rounding and ownership branches have 16 new synthetic mechanism cases. Final scheduler, override precedence, special wage cases and original runtime output are not covered by those cases.

**Value presence:** wave-3 opcode-level tests distinguish pointer-backed objects from inline boolean payloads. That boundary alone does not establish whether a saved false-valued field is returned by the default data-model getter. Wave 4 has begun tracing the original attribute filter and setter/getter chain. Do not apply the isolated presence tests to UI ownership behavior until that chain is closed. The frozen independent federal engine has not changed.

**Persistence:** original bodies expose named entities, manifests, conditional decryption and error paths. The original default save path requests encryption. Independent plain-ZIP probes therefore do not claim full default `.tax` support.

**Printing:** the complete FPS library yields actual allocation, length, free, option-layout and cache-access behavior. Resource interfaces also describe print lists and coordinate fields. Those resource descriptions are separate from renderer implementation; guessed flag meanings are not treated as proven.
