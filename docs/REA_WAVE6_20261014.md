## Template-driven typed loading

loader factories, namespace and field-ID matching, loader metadata and selected
value construction. Concrete virtual callbacks are bound to original vtable
bytes rather than inferred from names alone. Exact field IDs, optional legacy
aliases, array positions, source/override/computed attributes and value units
must remain distinct.

An independently authored, bounded intermediate-record adapter passes 85
synthetic mechanism probes. Root separately passes ten selected boundary probes.
It preserves original source text, selected numeric units and selected metadata;
known finite decimal ties round away from zero. Attribute boolean parsing differs
from checkbox text: native attribute `1` is false, while missing/empty `used`
defaults to true. Loose native substring cases are explicitly refused by the
adapter as an independent policy.

The adapter needs independently verified template metadata. It refuses unknown
templates, unknown fields, alias ambiguity, unsupported scalar/encoding and
unknown computed-loader context. Dates only have a studied pre-normalization
step; their final scalar conversion is refused. Logical strings do not recreate
the vendor string-table handles, and empty data is not declared equivalent to
absent/default runtime data. Atomic batch rejection returns no partial values.
This adapter is private experimental code and is **not an App `.tax` importer**.
