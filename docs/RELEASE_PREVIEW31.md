# Preview.31 — source interest comparison and decimal archive editing

The main Documents workflow now reads complete caller-local calculation resources and compares supported Schedule B L4 and Form 1040 L8A interest amounts. The complete source/profile/registration inputs are bound to the same release. Actual desktop cases cover the default $1,822.68 → $1,823 pair, an expanded $1,945.68 → $1,946 pair, an override retained at $999, and absent storage that creates a proposal only. Closing or changing the source invalidates the result. A cold offline browser reload also calculates and downloads the complete audit using cached App assets and local resource selection.

This is an interest comparison. Saved upstream interest and adjustment inputs are still used at explicit boundaries. The native inventory, output-row identity, dependency queue, TPS writeback and remaining original Form 1040 sequence are incomplete. The current IRS return and source file remain unchanged. [Workflow and limits](SOURCE_INTEREST_COMPARISON.md).

Independent ZIP/XML readback verifies the other 46 fields, all seven income candidates, manifest and four other local records. Decimal coefficients are not treated as income. [Workflow](MAC_DECIMAL_SOURCE.md).
