# REA progress, 2026-10-14

REA analysis and app implementation are separate. Original TurboTax 2025 binaries, resources, decompiler results, private finite interpreters and raw traces stay outside this repository. App code is independently authored against official IRS TY2025 rules.

The original fresh-year initialization prefix writes 2025, and the full dependent-inflation producer then yields the current Form 8814 thresholds. The decoded original allocation program was executed by a finite independent interpreter from raw child source amounts through the parent's final qualified-dividend destination. Separately, the original ordinary-tax callers and final tax aggregate were replayed with explicit synthetic parent taxable-income and filing-status leaves. Root independently verified frozen file hashes and reran the annual producer, twelve allocation cases and five parent tax aggregate cases. These are executions of decoded original programs in an independent interpreter, not executions of the original licensed application.

The app now connects an elected ordinary domestic Form 8814 profile to parent income, qualified/capital tax character, AMT comparison, NIIT, EIC investment-income and investment-interest calculations. Official per-child forms and parent supporting forms are filled from the actual calculation. The implementation and acceptance example are described in [child income election](child-income-election-2025.md).

The Windows legacy file path has progressed beyond container tags into packed field cells, actual hash-bucket chains, field-name/code dictionaries, amount kinds, compression frames and CRC. A guarded independent codec can read a selected packed field subsection and preserve/modify supported same-width numeric cells. Root verified the original byte ranges and reran the 32 subsection probes. This does not yet establish full `.tax` read/write: automatic form/container selection, linked or extended records, persistence variants, compression variants and original saved-file acceptance remain open. No new full `.tax` importer is advertised by this milestone.

Native multi-value flags, error propagation, date conversions, identifier text transformations and percent display have also been traced. Field applicability and complete scheduling/override behavior remain distinct from those recovered mechanisms. No license activation was bypassed.

The original activated application has not been executed and no original saved `.tax` fixture has been accepted. Full product parity, full file compatibility, pixel parity, every complex tax situation and electronic filing are not claimed. Three parallel REA chains continue: calculation resources and final tax dependencies; complete file/form read/write; native interpreter scheduling and field transformations.
