# Tax Reborn #000002 — 2026.10.14-preview.7

Preview.7 adds a working, reviewed TaxML-to-W-2 import and fixes desktop attachment persistence across a cold restart. The existing 2025 federal calculations, local returns, document review, backups, workpapers and official IRS PDF drafts remain available. Maintained by [@lxistired](https://github.com/lxistired).

## What changed

- Select actual plaintext XML bytes or an explicitly declared plaintext ZIP, together with a caller-supplied wire-profile JSON and matching caller-owned XPRF registry. Review a supported W-2 candidate, choose taxpayer or spouse, confirm the required amounts, append a separate W-2, recalculate and save it. Source bytes and an immutable receipt remain attached. Unknown facts, wrong semantic types, missing required source amounts and ambiguous copies block addition.
- Employer names use the supported CA/CA2 fields. The separate NAME caption is not treated as the employer. Missing Boxes 7 and 10 remain blank until explicitly reviewed; missing amounts do not establish zero. Appending a W-2 preserves previous statements and does not assert that all income has been reported.
- Desktop now uses a stable loopback origin for each local data directory. A cold restart retains attachment storage and the original imported source. The Windows launcher also prevents another process from sharing the same workspace listener.
- The Android wrapper includes sanitized lifecycle diagnostics and a visual reactivation callback. It does not clear storage or reload the interview when returning from a picker.

## Compatibility and continued REA work

This is a functional development preview. The new importer supports selected W-2 fields in explicitly bound plaintext XML/ZIP. It does not decrypt an encrypted .tax file, import a whole original return, write an original .tax return or establish original saved-file compatibility. Original tax-engine scheduling, setter/default/override state, complete liability paths and actual original-runtime comparisons remain open. The original executable was not run in the private static interpreter comparisons. E-filing, tax payment, expert representation and IRS acceptance are unavailable.

REA research continues on the original native loader, wrappers, arrays, calculation invalidation and scheduling. Federal formulas in the App are independently written from public IRS rules; the state drafts integrate the pinned open-source Invaro OpenTax engine. No Intuit binaries, original registry/resources, decompiler bodies, keys or proprietary artwork are distributed.
