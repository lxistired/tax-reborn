# Tax Reborn #000002 — preview.8

Preview.8 retains working2025 federal calculations, reviewed TaxML-to-W2 import,
local returns, source attachments, backup and official draft PDFs. It corrects
the supported UTF8 import boundary and aligns native package/runtime versions.

- UTF16/32 and conflicting encoding declarations are rejected before XML parsing.
  DTD/entities cannot pass through a different raw-byte encoding. Valid UTF8/BOM
  documents retain their exact source bytes/hash.
- Source regression:425 host methods;25 existing actual Pyodide TaxML contracts
  plus23 additional encoding input probes. The separate public825-case IRS AMT
  audit remains available.
- Windows x64 Setup was installed and its actual GUI edited withholding6500→7000,
  calculated refund1413→1913, saved, closed, reopened and exported a draft PDF.
  Built and installed frozen executables each passed12 checks. The installed
  worker passed25+23 encoding/metadata checks.
- Mac ARM64 read-only DMG payload375 files exactly match. Its actual frozen
  executable passes12 API/engine/persistence/draft checks and packaged worker
  passes25+23 checks. Preview7's native import/source retention/Save-panel
  workflow is documented separately; it was not rerun as a preview8 native GUI
  matrix.
- Android final same-key update was installed and the actual installed APK hash
  matches. Cold restart displayed retained synthetic P7/refund1425. Bundled
  worker assets pass25+23 checks. classes.dex is byte-identical to the accepted
  preview7 native wrapper. This release did not revalidate native document
  picker interactions or camera/OCR; USB/mirror input reliability remains open.

Version-specific [receipts](https://github.com/lxistired/tax-reborn/tree/main/qa/native-preview8)
and synthetic screenshots are included in the QA download. Windows actual
[acceptance run](https://github.com/lxistired/tax-reborn/actions/runs/38521471042)
used sourcebd9445e. Mac runtime uses the same source; Android guard/assets use

test-report and documentation changes. Exact hashes are in the manifest.

Actual REA binary work continues in three parallel chains: original file loading
and writing, calculation resources/graphs, and invalidation/execution scheduling.
[Wave8](https://github.com/lxistired/tax-reborn/blob/main/docs/REA_WAVE8_20261014.md)
separates new semantics from reused graph framing. Raw1099-DIV25/28% tax handling
is staged for the next version and is not silently included in these packages.

Full original .tax compatibility, activated original-runtime parity, all tax
situations and complete filing readiness remain unestablished. No e-filing or
tax payment. Mac ARM64 only; desktop packages unsigned/not notarized; Android
development signer. No Intuit binaries, key literals, original registries,
decompiler bodies or proprietary artwork are distributed.
