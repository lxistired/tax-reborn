Functional scope: every current default input and repeating-row-template field is editable through interview controls or Advanced Input JSON. All tax-result figures come from the API. Persistent saves use canonical UUIDv4 ids. Documents are separate local IndexedDB attachments; no cloud upload. A loaded local OCR/text module can suggest W-2 amounts for explicit review; extraction is not tax or document verification. No filing, acceptance, payment or expert-representation button is provided.

Responsive web/PWA UI does not establish native iOS support. A native Android host is independently packaged by the root task and requires its own build/emulator/device verification. Offline calculation uses root-owned local-api.js/tax-worker.js/Pyodide assets. Service-worker cache excludes /api and return data; extra static offline engine assets may be enumerated in offline-assets.json.

Final local integrations and license — 2026-10-13
The packaged app now includes root-owned document-import.js, local Tesseract OCR/language assets, readable-PDF text extraction, and a separate state workspace/worker. The frontend integrates candidate review and actual state saves; neither integration is proof of all-document recognition or complete vendor feature parity. The state worker combines the third-party OpenTax core/corpus/composition rules. These are public open-source inputs, not claimed as a REA-derived tax engine.
The combined Tax Reborn #000002 distribution is AGPL-3.0-only. Original independent MIT notices, upstream licenses and corresponding OpenTax source are retained by the root packaging task. Ledger Reborn #000001 remains separately MIT licensed.
The final PWA cache validates only explicitly enumerated, same-origin, non-API asset paths and rejects traversal. PDF forms, gzipped OCR models and extensionless license files are not excluded by filename type. User return endpoints are not cached by this worker.
